Este navegador no sirve para el panel

El panel escribe directamente en la carpeta del sitio en tu computador, y para eso necesita una función que hoy solo tienen los navegadores basados en Chromium.

Ábrelo en Chrome, Edge o Brave. En Firefox y Safari no funciona.

Administrar la flota

Agrega, edita o quita las máquinas que se muestran en la página. Los cambios se guardan en la carpeta del sitio en tu computador; después los publicas con un commit.

Por qué no hay contraseña

Este panel no guarda datos ni claves: está vacío hasta que tú le das acceso a una carpeta de tu computador. Si un desconocido abre esta dirección, ve este mismo formulario sin poder hacer nada, porque no tiene tus archivos. La llave es estar sentado frente a tu equipo, no una contraseña que podría filtrarse.

Elige la carpeta WEB, la que contiene index.html.

    Falta publicar

    Los cambios ya están escritos en tu carpeta, pero todavía no se ven en internet. Para publicarlos, haz commit y push del repositorio. GitHub se encarga de optimizar las fotos y regenerar la sección de flota.

    git add -A && git commit -m "Actualizar flota" && git push
